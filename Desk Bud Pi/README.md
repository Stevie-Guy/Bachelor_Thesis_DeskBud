# DeskBud

Asistent AI local pentru birou, rulează pe Raspberry Pi 5.

## Tehnologii
- Llama 3.2 (1B + 3B) prin Ollama
- faster-whisper pentru STT
- Piper pentru TTS
- Python 3.11+

## Instalare
\`\`\`bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
\`\`\`

## Rulare
\`\`\`bash
python3 main.py
\`\`\`
